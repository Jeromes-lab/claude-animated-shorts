# Kenney CC0 models (download yourself, not committed)

`src/videos/bridge/world.ts` loads these `.glb` files from this folder. Missing files are skipped, so
the short still renders without them, just without trees, flowers or market props.

From **Nature Kit** (https://kenney.nl/assets/nature-kit), copy the GLB versions of:
tree_oak, tree_default, tree_detailed, tree_fat, tree_cone, plant_bushLarge, plant_bushDetailed, plant_bush,
hedge, flower_redA, flower_yellowA, flower_purpleA, grass_large, grass, lily_large, canoe

From **Fantasy Town Kit** (https://kenney.nl/assets/fantasy-town-kit), copy the GLB versions of:
tree-high-round, tree, lantern, cart, stall-red, stall-green, stall-bench, banner-red, banner-green, windmill

If a kit only ships `.gltf`/`.fbx`/`.obj`, convert it to `.glb` (for example with Blender: File > Export > glTF Binary).
